# Gifts Corner - Fashion E-commerce Platform

A modern, responsive e-commerce web application built with React and Vite. This platform offers a seamless shopping experience with features like user authentication, product browsing, shopping cart management, and secure checkout.

## 🚀 Features

- **Responsive Design**: Built with Tailwind CSS logic for mobile-first responsiveness.
- **User Authentication**: Secure login and signup functionality using JWT and custom Auth Context.
- **Product Browsing**: Browse products by category with detailed product descriptions.
- **Shopping Cart**: Add items to cart, manage quantities, and proceed to checkout.
- **Order Management**: View past orders and track order status.
- **User Profile**: Manage user details and settings.
- **Modern UI**: Polished interface using Ant Design, Lucide React, and Framer Motion for smooth animations.

## 🛠️ Tech Stack

- **Frontend**: React (Vite)
- **State Management**: Redux Toolkit, React Redux
- **Styling**: Tailwind CSS, PostCSS
- **Routing**: React Router DOM
- **Forms & Validation**: React Hook Form, Zod
- **API Integration**: Axios
- **UI Components**: Ant Design, React Icons, React Spinners, React Loading Skeleton

## 📦 Installation

1.  **Clone the repository:**

    ```bash
    git clone <repository-url>
    cd fashion-web
    ```

2.  **Install dependencies:**

    ```bash
    npm install
    ```

3.  **Run the development server:**

    ```bash
    npm run dev
    ```

4.  **Build for production:**
    ```bash
    npm run build
    ```

## 🔧 Configuration

The application requires a backend API to function correctly. Ensure the `BASE_URL` in `src/api/base.api` is configured to point to your running backend server.
